# 版本与兼容性

DSH-Sharp 与 DSH 是两个独立发布物，不能把客户端版本当成服务版本。

## 当前契约

| 发布物 | 当前版本 | 说明 |
| --- | --- | --- |
| DSH-Sharp 客户端 | `0.2.1` | 桌面壳、服务托管与插件宿主 |
| DSH | 仅已验证版本 | 客户端声明的支持范围 |

已验证 DSH 版本：`0.1.0-rc.8`、`0.1.1-rc.2`。官方当前最新开发版本 `0.1.3-alpha.1` 尚未纳入支持范围；它包含 Session v2、会话生命周期和运行环境变更，不能按普通小版本直接升级。

## 设置页显示

设置页将信息分成两个独立区域：DSH-Sharp 客户端只显示客户端版本和客户端更新策略；DSH 运行时显示私有安装版本、实际监听地址、npm 最新版本、支持范围和兼容状态。DSH-Sharp 只管理私有运行时，不连接源码、远程或外部运行的 DSH。兼容性依据是私有安装的 `@deepseek-ai/dsh` 精确版本，不将 `host.describe` 的服务实例标识版本当作 DSH 包版本。

## 更新规则

首次安装后固定私有目录中的精确 DSH 版本。显式更新时先查询 npm，再使用 SemVer 判断目标版本是否落在当前 DSH-Sharp 支持范围内；越界版本会被阻止，避免客户端自动追踪不兼容的 `latest`。Runtime 与其 `DSH_HOME` 数据目录分离；更新不得清除会话、插件、设置或凭据。未来发布新客户端时，先更新兼容契约和验证矩阵，再开放新的 DSH 范围。

客户端自身的自动更新与 DSH 服务更新是两个独立流程，本版本只提供客户端版本信息，不自动下载客户端安装包。
