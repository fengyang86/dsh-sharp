# 版本与兼容性

DSH-Sharp 与 DSH 是两个独立发布物，不能把客户端版本当成服务版本。

## 当前契约

| 发布物 | 当前版本 | 说明 |
| --- | --- | --- |
| DSH-Sharp 客户端 | `0.2.0` | 桌面壳、服务托管与插件宿主 |
| DSH | `>=0.1.0-rc.8 <0.2.0` | 客户端声明的支持范围 |

已验证 DSH 版本：`0.1.0-rc.8`、`0.1.1-rc.2`。

## 设置页显示

关于与更新分别显示客户端版本、DSH 运行版本、私有安装版本、npm 最新版本、支持范围和兼容状态。源码模式只读取运行版本，不管理源码仓库的版本、依赖或构建；纯探测和远程服务同样不执行更新。

## 更新规则

Npx 模式首次安装后固定私有目录中的精确 DSH 版本。显式更新时先查询 npm，再使用 SemVer 判断目标版本是否落在当前 DSH-Sharp 支持范围内；越界版本会被阻止，避免客户端自动追踪不兼容的 `latest`。未来发布新客户端时，先更新兼容契约和验证矩阵，再开放新的 DSH 范围。

客户端自身的自动更新与 DSH 服务更新是两个独立流程，本版本只提供客户端版本信息，不自动下载客户端安装包。
